## When to use

Use when delivering UI with accessibility, responsive behavior, and explicit visual-evidence fallback.

## Workflow

Verify keyboard, semantics, contrast, and responsive behavior; document visual fallback when browser tooling is unavailable.

## Checks

Confirm evidence paths, approval policy, and surface fallback before claiming completion.

## Output

Return the procedure contract fields inside Handoff v1 without inventing unavailable tooling.
